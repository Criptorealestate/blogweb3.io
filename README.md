# Blog Web3

Sitio estático (HTML/CSS, sin build) para blogweb3.io — artículos sobre activos digitales,
tokenización inmobiliaria y cumplimiento regulatorio en México y El Salvador.

## Estructura

- `index.html` — página principal con listado de artículos
- `articulos/*.html` — artículos individuales
- `styles.css` — estilos compartidos

## Despliegue

Este proyecto está conectado a Vercel (proyecto `blogweb3.io`) y se despliega automáticamente
en cada push a `main`. No requiere build ni dependencias.
